## 심리학적 페이지 구조 (순서 변경 금지)

### 섹션 순서 및 심리 의도

```
1. HERO          → 패턴 인터럽트 (멈추게 만들기)
2. WARMER        → 공감 (내 얘기다 싶게)
3. WHY           → 인지 불협화음 (장비 문제 아님 → 충격)
4. EMOTIONAL     → 감성 타격 (억울함 자극)
5. PROOF         → 사회적 증거 (전후사진)
6. DIFF          → 해결사 등장 (리밋이 대안)
7. PRICE         → 저항 제거 (이 정도면 안 할 이유 없음)
8. CTA           → 행동 유도
```

**핵심 심리 원칙:**
- 가격은 반드시 차별점(DIFF) 뒤에 배치. 신뢰 구축 전 가격 노출 = 비교 사이트로 이탈
- 전후사진은 텍스트 설명 전에 넣지 말 것. 증거는 설득 후에 나와야 효과적
- CTA는 총 3번 등장: 히어로 하단 / PRICE 하단 / 스티키 바

### 2. HERO
**심리 의도:** 패턴 인터럽트. 3초 안에 멈추게 만들기. 헤드라인이 강해야 함.

**레이아웃:**
- 배경: `--cocoa` 다크 브라운
- 상단 배지 → 헤드라인 → 서브 → 전후사진 → 작은 CTA 순서

**카피:**
```
배지: 경기 북부 리프팅 1,000케이스+

헤드라인 (크고 임팩트 있게, Noto Serif KR 900):
"리프팅 효과 없는 거
당연한 겁니다.
제대로 안 했으니까."

서브 (작고 조용하게):
"장비 문제가 아닙니다.
어디를, 얼마나, 어떻게 설계하느냐가 전부입니다."
```

**이미지:** `ulthera2.png` (울쎄라 측면 전후)
- 이미지 아래 작은 CTA 버튼: "지금 이벤트 가격 보기 ↓" (스크롤 앵커, 카카오 링크 아님)

**UIUX 포인트:**
- "당연한 겁니다." 줄에 em 태그로 골드(#E8C9A0) 강조
- 헤드라인 텍스트 크기: clamp(28px, 7vw, 48px)
- 이미지에 box-shadow 강하게 (고급스러운 느낌)

---

### 3. WARMER — 공감 섹션
**심리 의도:** "내 얘기다" 싶게 만들어서 경계심 해제. 체크리스트 형태가 효과적.

**배경:** `--white`

**카피:**
```
라벨: 혹시 이런 경험 있으신가요

헤드: 이런 경험 있으시면
계속 읽어보세요

체크 리스트 (체크박스 UI, 체크된 상태로):
☑ 시술 받고 나서 달라진 게 없었다
☑ 멍만 들고 효과는 모르겠다  
☑ 상담에서 들은 것과 실제 시술이 달랐다
☑ 비용이 아깝다는 생각이 들었다
☑ 다음엔 어디서 받아야 할지 모르겠다
```

**UIUX 포인트:**
- 체크박스는 `--brown` 컬러로 이미 체크된 상태
- 각 항목 호버 시 살짝 강조
- 섹션 하단에 작은 텍스트: "하나라도 해당되신다면, 이유가 있습니다."

---

### 4. WHY — 실패 원인 분석
**심리 의도:** 인지 불협화음. "장비 탓이 아니었구나" → 기존 믿음 파괴 → 리밋이 대안으로 보이게 준비.

**배경:** `--ivory`

**카피:**
```
라벨: Why

헤드: 효과 없는 이유,
장비가 아닙니다

카드 3개:

[01] 일률적 매뉴얼 시술
내 얼굴이 아닌 평균 얼굴 기준으로 쏩니다.
얼굴 구조와 중력 방향을 보지 않습니다.

[02] 상담과 시술의 괴리  
들어간 순간 상담 내용은 사라집니다.
빠른 회전이 목표인 곳에서 정밀 설계는 없습니다.

[03] 사후관리 없음
시술실 나오는 순간 끝입니다.
경과 체크, 보완 구조가 없습니다.
```

**UIUX 포인트:**
- 카드에 왼쪽 border `--brown` 3px
- 번호(01/02/03)는 크게, 연한 색으로 배경처럼 깔기
- fade-up 애니메이션

### 5. EMOTIONAL — 감성 타격
**심리 의도:** 논리 이후 감정 자극. 억울함을 건드려서 행동 동기 강화.

**배경:** `--sand` (부드럽게)

**카피:**
```
헤드: 비싼 돈 내고
오히려 더 불안해졌다면

본문:
그건 시술이 문제가 아닙니다.
설계가 없었던 겁니다.

어디서 맞느냐보다,
어떻게 설계하느냐가 결과를 만듭니다.
```

**UIUX 포인트:**
- 텍스트 중심, 미니멀하게
- 폰트 Noto Serif KR, 무게감 있게
- 섹션 짧게 유지 (너무 길면 흐름 끊김)

---

### 6. PROOF — 전후 갤러리
**심리 의도:** 사회적 증거. 텍스트로 설득 후 시각적으로 확인시켜주기.

**배경:** `--white`

**카피:**
```
라벨: Real Results
헤드: 보정 없는
실제 전후 사진
```

**이미지 배치:**
- 2열 그리드
- 순서: ulthera2.png → ulthera1.png → lifting1.jpg → lifting2.jpg
- 각 이미지 탭하면 크게 보이는 라이트박스 (모바일 UX)

**이미지 아래 면책문구 (작게):**
```
실제 시술 고객님의 보정 없는 동일 조건 촬영 사진입니다.
모든 피부시술은 개인 피부 상태에 따라 결과가 다를 수 있습니다.
```

---

### 7. DIFF — 차별점
**심리 의도:** "리밋이 대안"임을 선언. 고객 언어로, 병원 자랑 언어 금지.

**배경:** `--cocoa` (다크, 신뢰감)
**텍스트:** 화이트 계열

**카피:**
```
라벨: 리밋의원 차별점

헤드: 리밋이 다른 건
딱 하나입니다.
"설계가 있습니다."

[01] 시술 전 원장이 직접 확인합니다
베드에서 원장이 피부 상태와 볼륨 분포를 체크합니다.
상담에서 들은 것과 실제 시술이 일치하는 구조입니다.

[02] 필요한 것만 합니다
1,000케이스 경험이 만든 냉정한 판단.
과잉 진단 없습니다.

[03] 강남 안 가도 됩니다
경기 북부 최대 규모, 전체 1인실.
장비와 시설은 강남 수준, 거리는 동네 병원입니다.
```

**UIUX 포인트:**
- 번호 크게, 골드(#E8C9A0)로
- 각 항목 구분선 `rgba(255,255,255,0.1)`
- fade-up 순차 애니메이션

---

### 8. PRICE — 가격
**심리 의도:** 저항 제거. "이 정도면 안 할 이유가 없다"는 느낌. 가격이 USP가 아니라 마지막 장벽 제거용.

**배경:** `--white`

**카피:**
```
라벨: 이번 달 한정 이벤트

헤드: 이 정도면
안 할 이유가 없습니다

가격 카드 3개:

[FEATURED - 온다 리프팅 4만줄]
🔥 가장 인기
44만원 → 22만원
1만줄당 5.5만원
* 조건 없음, 당일 예약 가능

[울쎄라 100샷]
40만원 → 28만원
* 400샷 이상 시술 시 적용

[써마지 100샷]  
50만원 → 40만원
* 300샷 시술 시 적용
```

**희소성 바:**
```
⏰ 하루 선착순 5명 — 꼼꼼한 시술을 위해 제한합니다
```
- 배경: 연한 노랑 `#FEF3C7`, 테두리 앰버

**UIUX 포인트:**
- FEATURED 카드는 `--cocoa` 배경, 가격 골드
- 나머지 카드는 `--ivory` 배경
- 가격 숫자 크게 (clamp 24-36px)

## 전체 UIUX 원칙

### 애니메이션
- 모든 섹션 `fade-up` (opacity 0 → 1, translateY 24px → 0)
- IntersectionObserver로 스크롤 시 트리거
- 카드 여러 개일 경우 stagger (0.1s 간격)

### 모바일 최적화 (최우선)
- max-width: 480px, 중앙 정렬
- 터치 타겟 최소 44px
- 이미지 lazy loading (히어로 제외)
- 폰트 clamp로 반응형

### 타이포그래피
- 헤드라인: Noto Serif KR 700/900
- 본문: Noto Sans KR 300/400
- 강조: em 태그, 골드(#E8C9A0) 또는 언더라인

### 이미지
- 히어로: `ulthera2.png` eager loading
- 갤러리: 4장 모두 lazy loading
- 갤러리 탭 시 라이트박스로 크게 보기

### 금지사항
- 형광톤 컬러 사용 금지
- 과도한 이모지 사용 금지
- 병원 자랑 언어 ("최고", "최상" 등) 금지
- 주소/진료시간은 실제 정보로만 입력 (플레이스홀더 그대로 두기)
